🎯 Platform Overview

Exam Hub is a comprehensive online examination and assessment platform designed specifically for UP LT Grade Computer Science preparation. It provides administrators with powerful tools to manage students, create tests, evaluate submissions, and track academic progress.

Purpose: Streamline exam administration, assessment, and student evaluation for competitive exam preparation.

🚀 Getting Started

Admin Login

  • Navigate to the admin login page
  • Enter your Admin ID (provided by system administrator)
  • Enter your Password
  • Click "Sign in as admin"
  • You will be redirected to the Admin Dashboard
🔒 Security Note: Keep your admin credentials confidential. Never share your password with anyone. The system uses secure session management to protect your account.

📈 Admin Dashboard

The Admin Dashboard is your command center for platform-wide oversight and management.

Dashboard Overview

The dashboard displays four key metrics:

Metric Description Use Case
Total Students Total number of active student accounts Platform size and enrollment tracking
Total Submissions Cumulative test submissions by all students Platform activity and usage metrics
Pending Evaluations Number of ungraded submissions awaiting review Workload management and priority tasks
Published Tests Total number of active tests available to students Content availability monitoring

Dashboard Sections

Top Performers Section: Displays the highest-ranking students based on average marks. Click "View all" to access the complete student management panel.
Pending Evaluations Queue: Shows submissions awaiting your evaluation. Displays student name, test title, and number of uploaded files. Click "Open queue" to begin evaluating submissions.

👥 Student Management

Manage all student accounts, create new accounts, and control student access to the platform.

Creating Student Accounts

1 Navigate to the Students menu from the sidebar
2 Click the "Add Student" button
3 Enter the student's full name
4 Create a strong password for the student account
5 Click "Create account" to finalize

Searching and Managing Students

  • Search Function: Use the search bar to find students by name or Student ID
  • View Details: Each student row displays name, user ID, password, and status
  • Toggle Status: Use the switch to activate/deactivate student accounts
  • Delete Student: Click the delete button to remove a student (warning: this is permanent)
💡 Tip: Provide students with their User ID and Password securely. Ensure each student keeps their credentials confidential.

📝 Test Management

Create, edit, and publish tests with multiple-choice and descriptive questions.

Creating a New Test

1 Navigate to the Tests menu
2 Click "New Test" button
3 Enter the test Title (e.g., "Algebra II Midterm")
4 Select the Subject area
5 Set a Deadline for test submission

Adding Questions

Two Question Types Supported:

  • Text Questions: Enter question text directly or upload an image
  • Image Questions: Upload question images from your device
1 Click "Add Question" to add a new question to your test
2 Select question type (Text or Image)
3 Enter the question text (or upload image)
4 Assign marks/points for this question
5 Repeat for all questions

Test Status Management

Status Description Student Access
Draft Test is being prepared, not yet ready Not visible to students
Published Test is live and ready for submissions Visible and available to all students
📌 Best Practice: Always create tests in draft mode first. Review all questions and answers before publishing to ensure accuracy.

✅ Submissions & Evaluations

Review and evaluate student test submissions with detailed feedback.

Evaluating Submissions

1 Navigate to Evaluations menu from sidebar
2 View the queue of pending submissions
3 Click on a submission to open evaluation interface
4 Review student answers (displayed as uploaded images/files)
5 Assign marks out of the total marks for the test
6 Provide constructive feedback for the student
7 Click "Submit Evaluation" to finalize

Submission Details

  • Student Name: Name of the student who submitted
  • Test Title: Name of the test submitted
  • Submission Files: All answer files uploaded by student
  • Timeline: View when submission was made

📢 Notices Management

Post important announcements and messages to all students.

Creating a Notice

1 Navigate to Notices from sidebar
2 Click "New Notice" button
3 Type your announcement message
4 Click "Post Notice" to publish

Notice Best Practices

  • Keep notices clear and concise
  • Include important deadlines
  • Provide any relevant instructions
  • Use notices for schedule changes or important updates
  • All notices are visible to all students immediately
💬 Notice Types: Use for test schedules, deadline extensions, platform maintenance notifications, study material updates, and important announcements.

💡 Best Practices & Tips

Student Management

  • Create student accounts at the beginning of each term/batch
  • Use standardized naming conventions for easy identification
  • Deactivate accounts for students who are no longer active
  • Keep a backup record of student credentials

Test Creation

  • Start with draft mode to allow for revisions
  • Ensure all questions have clear, unambiguous wording
  • Verify image uploads are clear and readable
  • Set realistic deadlines that allow students adequate time
  • Test the platform yourself before publishing tests

Evaluation Process

  • Check pending evaluations regularly
  • Provide constructive and detailed feedback
  • Be consistent in marking criteria across all submissions
  • Evaluate submissions promptly so students get timely feedback

Communication

  • Post important notices in advance (not last minute)
  • Use clear, professional language in all communications
  • Inform students of any system maintenance or downtime
  • Respond to student concerns promptly
