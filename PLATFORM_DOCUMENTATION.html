🚀 Quick Start Guide

For Administrators:

  1. Open Admin Login page
  2. Enter your Admin ID and Password
  3. Click Sign in as admin
  4. You'll see your Admin Dashboard
  5. Use the sidebar to navigate to:
    • Students (manage accounts)
    • Tests (create and publish)
    • Evaluations (grade submissions)
    • Notices (post announcements)

For Students:

  1. Open Student Login page
  2. Enter your Student ID and Password
  3. Click Sign in as student
  4. You'll see your Dashboard with your statistics
  5. Use the main menu to:
    • View Available Tests
    • Submit Your Answers
    • Check Leaderboard
    • Read Notices

❓ Frequently Asked Questions

Q: How do I access the guides?
A: Click the "Read Admin Guide" or "Read Student Guide" buttons above to open the HTML documents. You can print them or save them as PDFs using your browser's save/print function.
Q: Can I save these guides as PDF?
A: Yes! Open the guide in your browser, press Ctrl+P (or Cmd+P on Mac), and choose "Save as PDF" from the print dialog.
Q: How do I print the guides?
A: Open the guide in your browser, press Ctrl+P (or Cmd+P on Mac), and select your printer to print.
Q: Can both guides be used offline?
A: Yes! Save the HTML files to your computer and open them with any web browser. They work completely offline.
Q: Which guide should I read?
A: Administrators should read the Admin Guide. Students should read the Student Guide. Both guides are comprehensive and specific to each role.
Q: Are there video tutorials available?
A: These HTML guides are comprehensive. For additional support, contact your system administrator or instructor.
